Comportement du flow

Arrêt sur erreur

Interrompt le pipeline dès qu'une phase échoue. Décoché : les phases suivantes tentent quand même.

Tentatives par phase

Nombre de relances automatiques d'une phase échouée (0 = aucune).

Compaction agressive du contexte

Borne le résultat transmis d'une phase à la suivante (4 000 premiers caractères).

Budget max (tokens)

Stoppe le pipeline avant une phase si le cumul dépasse cette limite. Vide = illimité.

Log détaillé

Trace les phases et erreurs du pipeline dans la console du navigateur.
